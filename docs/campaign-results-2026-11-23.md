## Договоры выпуска

- Установщик принимает закреплённые SHA‑256 CMD, ZIP и восьми инструментов.
  Итоговый отчёт установки публикуется после подготовки, проверки локального
  `normal` и запуска опроса. Установленный комплект отображается в TUI по
  свежему отчёту зарегистрированного ПК.
- Рабочая SQLite контроллера принадлежит служебной учётной записи
  `examcontroller`. Историческая база сохранена. Учётная запись `examowner`
  открывает по SSH только TUI. Снятие принимает сервер для конкретной тревоги,
  ревизии, загрузки и сеанса Guest. TUI ждёт подтверждения Windows.
- Локальный `normal` остаётся штатным заданием Windows. Он снимает собственные
  ограничения и останавливает выделенный Wazuh. Строка «Ограничения сняты · вход
  проверить» означает, что исходные настройки очищены. Чтение USB, сеть и старый
  проект дополнительно проверяются в обычном входе.

  подтверждает сдачу. Экспорт исключает JAR из студенческого пакета. Отдельный
  проверяемый этап узкой сборки добавляет официальный Wrapper по закреплённому
  SHA‑256. Исходники курса `2befc28`, сценарий сборки `c8984fa`, подключённый Native
  `cfeae403de7b2f2acd17439e20becd8cb0f41523`. Тома PrairieLearn совпали до и после
  смены каталога. Байты ZIP по подписанному Moodle → LTI маршруту из существующей
  тестовой попытки дали SHA‑256
  `aca01a7066efbe205d9089f4d32e32d2e2c0aaaa4da1cc611ca2cc8c69808f2e`.
