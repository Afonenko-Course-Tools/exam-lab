# Первое открытие заготовки Java в IDEA

1. В новом входе Shared PC Guest скачайте `starter.zip` из работы «Числовые
   вычисления» в PrairieLearn и распакуйте в свою папку.
2. Отключите сеть после скачивания. Запустите ярлык **ExamLab - IDEA**, выберите
   **Open** и укажите распакованную папку, где лежат `settings.gradle` и
   `gradlew.bat`. На штатный запрос доверия IDEA ответьте **Trust Project**.
3. Дождитесь синхронизации. В проекте должен использоваться JDK 25, а Gradle
   Wrapper должен запустить 9.8.2. Запустите задачу `test` в панели Gradle IDEA.
   После реализации программы обе проверки должны пройти, включая приветствие
   для имени «Анна». Запустите `Main`, поставьте точку останова и проверьте
   **Debug** из редактора.
4. Восстановите сеть, отправьте `Main.java` из той же работы и дождитесь оценки
   той же попытки. В обычном входе до экзамена и после `normal` проверьте прежний
   проект обычным ярлыком IDEA.

Курс задаёт Java toolchain в `build.gradle`, публикует штатный Gradle Wrapper с
SHA-256 дистрибутива и сохраняет незаполненную заготовку и открытые тесты. В
Windows launcher JDK 25 преобразует аргументы через системную кодовую страницу.
Тестовый помощник передаёт аргументы вложенной JVM через служебный UTF-8-файл,
чтобы проверка действительно передала имя «Анна» основному методу студента.

`Install-ExamLabIdea.ps1` берёт проверенный путь JDK из итогового отчёта
`Prepare-ExamLab.ps1`. При первом запуске ярлык создаёт отдельные каталоги
IDEA и Gradle в `%LOCALAPPDATA%\ExamLab\IDEA`. Ярлык передаёт `JAVA_HOME`,
`GRADLE_USER_HOME`, `GRADLE_RO_DEP_CACHE` и `IDEA_PROPERTIES` своему процессу.
Обычная IDEA продолжает использовать настройки своего профиля.
[Свойства IDEA](https://www.jetbrains.com/help/idea/directories-used-by-the-ide-to-store-settings-caches-plugins-and-logs.html)

Установщик проверяет SHA-256 исходного ZIP Gradle. Ярлык копирует ZIP из
защищённой установки в штатное место Gradle Wrapper. Wrapper сверяет
контрольную сумму при распаковке. Init script включает автономное разрешение
зависимостей в этом пользовательском каталоге Gradle, а общий `modules-2`
открывается для чтения. Java plugin поставляется в самом Gradle.
[Хеши Gradle](https://gradle.org/release-checksums/)

Для диагностики сохраните сборочный вывод и `%LOCALAPPDATA%\ExamLab\IDEA\log\idea.log`.
Холодное открытие проверяют из нового настоящего Guest с отключённой сетью и
без уже распакованного Gradle Wrapper. Рабочие данные и журналы Guest хранятся
вне Git.
