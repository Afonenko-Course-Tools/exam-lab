# Переиспользование поставки exam-lab 0.1.0

Поставка `exam-lab-0.1.0.zip` пригодна как источник небольших проверенных частей.
Целиком переносить прежнюю архитектуру не следует: согласованные границы
восстановления, USB и управления изменились.

Внутренний манифест указывает commit `8cc98c23e82f089a6f1ad71322080070bc7ce482`;
все 80 перечисленных файлов совпали с его контрольными суммами. Это проверка
внутренней целостности, а не внешней подписи. Архив и Windows-образы не добавляются
в новый репозиторий.

## Полезные части

- Небольшой Python CLI, проверка конфигурации и запуск существующих инструментов.
- PowerShell-функции SharedPC, AppLocker, USB и сети с сохранением исходного состояния
  и чтением результата после изменения.
- Отказ от смены режима при загруженных посторонних пользовательских профилях.
- Существующие Pester и Python-тесты как материал для адресных проверок.

Python CLI не управляет жизненным циклом тестовой Windows VM. Ansible-роли не
являются клиентом исходящего опроса. Готового производственного polling в 0.1.0 нет.

## Что нужно изменить или проверить

| Часть | Ограничение прежней поставки | Действие |
| --- | --- | --- |
| USB | Сохраняется широкий набор PnP-устройств и ограничивается установка устройств всей машины. | Проверить более узкий запрет чтения для экзаменационного пользователя. |
| IDEA | Seed попадает в `C:\Users\Default`, влияя на все будущие профили; полноценная подготовка IDEA не автоматизирована. | Привязать экзаменационные настройки к экзаменационной среде, проверить настоящий первый запуск. |
| Общие каталоги | Часть ACL меняется постоянно и не восстанавливается через `normal`. | Не закрывать обычные учебные каталоги; определить необходимые границы доступа. |
| SharedPC | Настраивается при подготовке и не возвращается ролью `normal`. | Проверить весь выбранный машинный набор настроек на обычных занятиях. |
| Firewall | Меняет общую политику компьютера. | Проверить сохранность управления и автономное восстановление без контроллера. |
| Управление | `normal` оформлен Ansible-ролью. | Сделать локальное завершение через те же функции, доступное без сервера. |
| Инфраструктура | Nix/OpenTofu относятся к Linux-контроллеру; Windows desktop VM не поставляется. | Не включать этот слой в обязательный первый пилот. |

В сетевом модуле обнаружены два адресных сценария для исправления и тестов:
дрейф группы существующего управляющего firewall-правила может привести к его
отключению; прерывание между удалением сохранённого состояния и активного маркера
может сломать повторный `normal`. Они не означают, что любой первый запуск
обязательно приводит к отказу.

## Выполненная проверка

На исходной поставке прошли 47 Python-тестов за 0,96 секунды с отключённой
автозагрузкой сторонних pytest-плагинов. Они проверяют переносимую логику и
подменённые взаимодействия. Реальные Windows-политики, очистка Guest, физический
USB и полный учебный маршрут этим результатом не подтверждаются.

Старые архивы ExamLock рассматриваются отдельно. Их ошибки не переносятся
автоматически на оценку 0.1.0; исходящий опрос берётся как организационная схема,
без старого автоматического снятия ограничений при потере связи.
