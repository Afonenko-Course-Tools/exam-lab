# Сквозная ручная приёмка exam-lab

Испытание рассчитано на два часа на одноразовой Windows x64, 8 ГБ,
с виртуальной флешкой и маршрутом к выделенной VM `10.135.250.231`.
Лист запуска выпуска содержит SHA-256, ссылку на CMD, SSH-профиль владельца
и данные синтетического входа Moodle. Оператор стенда заранее открывает
короткое окно регистрации для этого ПК. Для запуска на Windows нужен только CMD.

## Установка и повтор

1. Войдите в обычную учётную запись администратора Windows. На свежем образе
   завершите первоначальную настройку и перезагрузите ПК.
2. Откройте в Edge `http://10.135.250.231/Start-ExamLab.cmd` и сохраните файл.
   Если Edge попросит подтвердить сохранение, нажмите «Сохранить».
   В обычной командной строке проверьте его SHA-256.

   ```cmd
   certutil -hashfile "%USERPROFILE%\Downloads\Start-ExamLab.cmd" SHA256
   ```

   Сверьте все 64 символа со значением из листа выпуска. При совпадении
   откройте скачанный CMD и подтвердите UAC. CMD устанавливает сертификат,
   получает PowerShell 7 и запускает проверенный установщик по HTTPS.
   Регистрация контроллера и Wazuh проходит автоматически. Если система попросит
   перезапуск, перезапустите Windows и откройте тот же проверенный файл.
3. Дождитесь сообщения об успешном завершении. Повторите запуск тем же CMD.
   В панель должен прийти свежий итоговый отчёт той же версии. В Windows
   должна остаться одна запись ExamLab. При ошибке сохраните выведенный номер
   отчёта. Если сеть недоступна, окно покажет путь к локальному архиву.

## Проверка с места преподавателя

Импортируйте выданный SSH-профиль в Muon по инструкции к листу запуска.
Подключитесь как `examowner-ssh`, откройте терминал и введите `exam-lab-tui`.
Выберите строку мышью
или стрелками. `Enter` открывает действия выбранного ПК. Для группы отметьте
строки пробелом. Кнопки «Экзамен» и «Обычный» показывают результат каждого
отмеченного ПК по мере его получения. Снятие текущей тревоги доступно
владельцу в меню действий места.

При первом запуске IDEA пройдите начальный экран JetBrains. После возврата
сети дождитесь свежей строки того же ПК в TUI перед контрольной тревогой.
На чистой VM до назначения экзамена зайдите обычным пользователем
`labstudent`, сохраните тестовый файл в «Документах» и выйдите из сеанса.
После `normal` снова откройте тот же файл и проверьте флешку.

## Аварийный локальный normal

Выйдите из Guest. Войдите в обычную административную учётную запись Windows,
оставив сеть до сервера отключённой. В командной строке от имени администратора
запустите установленное задание.

```cmd
schtasks /Run /TN ExamLab-Local-normal
```

Дождитесь завершения задания. Выйдите и заново войдите в обычную учётную
запись. Переподключите виртуальную флешку, откройте обычный файл и прежний
проект. После восстановления связи проверьте, что старое назначение
не возвращает экзаменационный режим.

## Экзамен с записью файлов

1. В TUI владельца нажмите «Экзамен с записью файлов» или `F2` и проверьте
   название открытого экзамена. Выберите ПК, нажмите «Экзамен» и подтвердите
   назначение. Дождитесь допуска машины.
2. Войдите в новый Guest. В его каталоге создайте, откройте и переименуйте
   синтетический файл. Запись стартует для этого Guest и автоматически
   останавливается по таймеру или при завершении режима. На ПК с 8 ГБ при
   параллельной работе IDEA фиксируйте пиковую память и потери событий ETW.
3. Выйдите из Guest. Для короткой пробы запустите локальный `normal` по
   инструкции выше. Дождитесь отметки о локальном снятии в TUI и нажмите
   «Обычный». Если сервер доступен по Ethernet, проверьте поступление архива на стенд.
   При подключении только по Wi-Fi войдите в обычную административную учётную
   запись и откройте `C:\Program Files\ExamLab\Show-ExamLabFileTrace.cmd`. Скопируйте
   архив из открывшегося Проводника на диск. Оставьте исходный архив на ПК до
   проверки копии. В журнале приёмки укажите фактически проверенный тип связи.

Используйте синтетические данные. Испытание со студентами проводится в отдельном
окне. Архив содержит пути файлов и сведения о процессах. Доступ к нему ограничен
оператором пилота.
