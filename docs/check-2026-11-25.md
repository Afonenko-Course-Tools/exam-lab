RC20 дал русский итог и квитанцию при запуске под обычной учётной записью
на Windows 104 через WinRM. Двойной щелчок на RC20 ещё предстоит проверить.
Для обследования по уже принятому маршруту доступен RC18.

Сверьте SHA-256 скачанного файла с переданным отдельно значением. В PowerShell,
открытом в папке со скачанным файлом, выполните:

```powershell
Get-FileHash -LiteralPath .\Check-ExamLab.cmd -Algorithm SHA256
```

При совпадении с хешем выбранного выпуска откройте CMD двойным щелчком
из обычной учётной записи Windows
и дождитесь итоговой строки. Check использует встроенный Windows PowerShell
5.1 и собирает доступные текущему пользователю сведения о ПК.

- `Diagnostics accepted` показывает номер принятого архива. Запишите этот
  номер вместе с обозначением рабочего места.
- `Local diagnostics` показывает папку отчёта. Если квитанции нет, найдите
  в этой папке `diagnostics.zip` и сохраните его для закрытой передачи. После
  восстановления связи можно повторить запуск для штатной повторной отправки.
- В RC20 эти строки подписаны **Номер принятого архива** и **Локальный ZIP**.
  Итог сохраняется также в `check-result.txt` рядом с архивом.

Приёмник принимает до 8 МиБ в одном запросе. Сырые ZIP передавайте через
согласованный закрытый канал. Лист проверки для обсуждения может содержать
обозначение ПК, номер отчёта и наблюдавшийся результат запуска.
