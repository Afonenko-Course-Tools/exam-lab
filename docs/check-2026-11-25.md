# Обследование аудиторных ПК 25 ноября 2026 года

Скачайте `Check-ExamLab.cmd` в сети стенда. Основной выпуск на 25 ноября —
RC20 из ревизии `2f9865ed3bb0ab2c031ff082d5ff765c9826fdee`.
[Скачать RC20](http://10.135.250.231/c)

Откройте PowerShell в папке со скачанным файлом и вычислите SHA-256.

```powershell
Get-FileHash -LiteralPath .\Check-ExamLab.cmd -Algorithm SHA256
```

Ожидаемый SHA-256 — `bb1731c1e78724503afb5a20ef95eb709d68145bd4c66e747e57b423c9fc4148`.
При совпадении откройте CMD двойным щелчком из обычной учётной записи Windows
и дождитесь итоговой строки. Check использует встроенный Windows PowerShell
5.1 и собирает доступные текущему пользователю сведения о ПК.

- **Номер принятого архива** показывает квитанцию. Запишите этот
  номер вместе с обозначением рабочего места.
- **Локальный ZIP** показывает путь к `diagnostics.zip`. Если квитанции нет,
  сохраните ZIP для закрытой передачи. После восстановления связи можно
  повторить запуск для штатной повторной отправки.
- Итог доступен также в `check-result.txt` рядом с архивом.

Приёмник принимает до 8 МиБ в одном запросе. Сырые ZIP передавайте через
согласованный закрытый канал. Лист проверки для обсуждения может содержать
обозначение ПК, номер отчёта и наблюдавшийся результат запуска.

Запуск RC20 двойным щелчком подтверждён на VM 105 с Windows 10 22H2
под обычной учётной записью, без запроса повышения прав. Русский итог
показал номер принятого архива. Размер и SHA-256 копии на сервере совпали.
