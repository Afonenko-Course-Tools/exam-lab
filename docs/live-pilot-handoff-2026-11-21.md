# ExamLab. От скачивания до сдачи

Пройдите шаги по порядку. Установку и сдачу вы выполняете в окне Windows.
Назначение экзамена и допуск Guest выполняются на VM 103 в терминале Muon SSH.

## 1. Скачайте и запустите установщик в Windows

1. Откройте окно **ExamLab - Windows VM**. Если его нет, на ноутбуке запустите
   `remote-viewer vnc://127.0.0.1:5917`.
2. Войдите в Windows как `examadmin` с паролем `Exam123!`. Все пароли в этой
   инструкции вводятся в английской раскладке.
3. Откройте Edge и введите в адресной строке **`http://10.135.250.231/`**.
   Браузер скачает `Start-ExamLab.cmd`. Откройте папку **Загрузки**, нажмите
   на файл правой кнопкой и выберите **Запуск от имени администратора**.
4. Дождитесь сообщения `ExamLab installation and Shared PC preparation completed.`
   и появления ярлыка **ExamLab - Moodle** на рабочем столе. Пакеты и кеш Gradle
   скачиваются с VM 103 по HTTPS, регистрация ПК уже подготовлена. Во время
   скачивания IDEA в окне установки видны проценты и объём загрузки. Затем
   скрипт по очереди указывает, какую программу он проверяет или устанавливает.
   Тихая установка IDEA может занять несколько минут. Полные отчёты лежат
   в `C:\Program Files\ExamLabSetupReports`.

Оставьте Windows открытой и переключитесь в Muon SSH.

## 2. Назначьте экзамен и дождитесь разрешения на вход

На ноутбуке в Muon SSH нажмите **New connection** и заполните поля.

| Поле | Значение |
| --- | --- |
| Host | `10.135.250.231` |
| Port | `22` |
| Username | `examadmin` |
| Private key file | `/home/tolya/.ssh/exam-lab-pilot-ed25519` |

Нажмите **Connect**, затем откройте **Terminal**. Поле пароля оставьте пустым.
Если Muon просит подтвердить ключ сервера, сверяйте отпечаток ED25519
`SHA256:+GDkpJiPVUI7LwdXwAQbVB1jA2mHF7rjFZXSCtb/a2k` или его вид в старом формате
`23:d8:90:37:a9:93:51:6f:e1:a9:05:3d:c3:fc:59:5d`.

В терминале на VM 103 назначьте экзамен. Оставьте этот сеанс открытым,
чтобы переменная `device` сохранилась для следующих шагов.

```bash
device=pilot-win-handoff-20261121
~/exam assign "$device" exam --exam-id "manual-$(date +%Y%m%d-%H%M%S)"
```

Перезапустите Windows из меню **Пуск**. Оставьте её на экране входа.
На сервере выполняйте `~/exam readiness`, пока в строке
`pilot-win-handoff-20261121` в колонке **Можно входить** не появится **да**.
Это подтверждение, что ПК применил машинные политики в текущей загрузке.

Ту же сводку можно открыть в браузере с доверенным CA пилота. Для входа
используйте `pilot-teacher`, пароль `Teach12!`.
[Панель преподавателя](https://10.135.250.231:21650/exam/teacher/readiness)

## 3. Войдите как Guest и подтвердите допуск студента

1. После **Можно входить = да** в Windows войдите как `examadmin` и откройте
   **Windows PowerShell** от имени администратора. Запустите сбор Wazuh.

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$env:ProgramFiles\ExamLabWazuh\Install-ExamLabWazuh.ps1" -Action StartCollection
   ```

   Параметр `-ExecutionPolicy Bypass` действует только в этом запуске PowerShell.
   На сервере выполните `~/exam wazuh-status`. Когда агент покажет `Active`,
   выйдите из `examadmin`, выберите плитку **Guest** и нажмите **Sign in**.
   У гостевой учётной записи Windows нет отдельного пароля.
2. В Guest попробуйте открыть `E:\test-marker.txt` с тестовой флешки и
   `C:\Users\examadmin\Documents\ExamLab-Control.txt` из обычного профиля.
   Оба файла должны дать отказ в чтении. Проверьте, что IDEA открывается
   и Guest может сохранить учебный файл в своей папке.
3. На сервере выполните `~/exam readiness`. В свежей строке возьмите три значения
   из колонок **Ревизия**, **Загрузка UTC** и **Guest**. Подставьте их в команду после
   успешных проверок в этом сеансе.

   ```bash
   ~/exam confirm-guest "$device" --revision РЕВИЗИЯ --boot-utc UTC_ЗАГРУЗКИ \
     --guest-session-id ID_СЕАНСА --file-probe --project --wazuh
   ~/exam readiness
   ```

Когда в колонке **Можно начинать** появится **да**, переходите к сдаче.
Если Guest вышел или Windows перезагрузилась, подтвердите новый сеанс.
Для проверки самой тревоги используйте [сценарий контрольного события](../vm/proxmox/wazuh/README.md#проверка-одного-события).

## 4. Сдайте работу и верните обычный режим

В Guest откройте **ExamLab - Moodle**. Войдите в Moodle как
`pilot_student_20261121` с паролем `Moodle1!`. Откройте через LTI работу
**Числовые вычисления** и скачайте заготовку.

Распакуйте проект и откройте его в IDEA. В окне **Open Gradle Settings**
или через **Settings → Build, Execution, Deployment → Build Tools → Gradle**
задайте параметры проекта.

- **Gradle JVM** — JDK 25. Если его нет в списке, выберите **Add JDK** и
  укажите `C:\Program Files\Eclipse Adoptium\jdk-25`.
- **Distribution** — **Local installation** (или **Specified location**) с
  путём `C:\Program Files\gradle-9.8.2`.

Сохраните настройки. В панели **Gradle** включите **Toggle Offline Mode**
и повторите синхронизацию проекта. Зависимости берутся из кэша пилота.
[Настройки Gradle в IDEA](https://www.jetbrains.com/help/idea/gradle-settings.html)

После редактирования откройте PowerShell в папке проекта и запустите тесты.

```powershell
$env:JAVA_HOME = "$env:ProgramFiles\Eclipse Adoptium\jdk-25"
& "$env:ProgramFiles\gradle-9.8.2\bin\gradle.bat" --offline test
```

Отправьте запрошенные исходники через форму PrairieLearn. Дождитесь результата
и запишите номер попытки и оценку.

Выйдите из Guest. На сервере выполните `~/exam assign "$device" normal`.
Командой `~/exam status "$device"` дождитесь свежего отчёта о режиме `normal`.
Войдите в Windows как `labstudent` с паролем `Lab1234!`. Проверьте, что снова
открывается `E:\test-marker.txt` и доступна обычная сеть. Отдельная проверка
завершения при недоступном сервере описана в [сценарии приёмки](manual-proxmox-acceptance.md#маршрут-приёмки).

## Как повторить маршрут на нескольких ПК

На сервере публикуется один выпуск. На каждом подготовленном ПК администратор
открывает тот же HTTP-адрес, скачивает один CMD и запускает его. Закрытую
регистрацию контроллера и Wazuh готовят на каждый ПК заранее; размещённые в
`%ProgramData%\ExamLabPilotInput` файлы подхватываются при этом же запуске.
В текущем прогоне HTTP открыт источнику ноутбука. Для следующего стенда его
ограничивают согласованной сетью компьютеров, которые проходят подготовку.
[Серверная публикация и регистрация](manual-proxmox-acceptance.md#подготовка-proxmox)
